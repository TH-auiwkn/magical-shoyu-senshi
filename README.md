# マジカル☆しょうゆ戦士 公式サイト

架空のマンガ『マジカル☆しょうゆ戦士』の公式サイトです。
https://th-auiwkn.github.io/magical-shoyu-senshi/

> 変身しても、表情は変わらない。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | サイト本体（1ページ構成） |
| `assets/css/style.css` | スタイル |
| `assets/js/main.js` | 表情集の切り替え、技名の演出、マンガの拡大表示など |
| `assets/img/` | キービジュアル、マンガの原稿、各種切り抜き画像 |

ビルドは不要です。静的ファイルをそのまま配信すれば動きます。

## ローカルで見る

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開いてください。

## エピソードを公開する

1. 原稿画像を `assets/img/` に追加します。ファイル名には話数とページ番号を含めます（例 `episode-2-page-1.webp`）。
2. `index.html` のエピソード一覧に、第1話と同じ構造で原稿画像とページ番号を並べます。準備中のエピソードを公開する場合は、「公開準備中」と案内文を外し、原稿を追加します。新しいエピソードには `episode-3` のような固有の ID を付けます。
3. `main` の変更を公開ブランチの `gh-pages` に取り込みます。

## 設定メモ

- マジカル☆しょうゆ戦士の表情は、どの場面でも一切変化しません。
- 必殺技は「ジャスティス♡マグナム」を含む全9種。いずれも素手です。
- この作品はフィクションです。実在の人物・団体・しょうゆとは関係ありません。
