# マジカル☆しょうゆ戦士 公式サイト

架空のマンガ『マジカル☆しょうゆ戦士』の公式サイトです。
https://th-auiwkn.github.io/magical-shoyu-senshi/

> 変身しても、表情は変わらない。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | サイト本体（1ページ構成） |
| `assets/css/style.css` | スタイル |
| `assets/js/main.js` | 表情集の切り替え、技名の演出、試し読みの拡大表示など |
| `assets/img/` | キービジュアル、第1話の原稿、各種切り抜き画像 |

ビルドは不要です。静的ファイルをそのまま配信すれば動きます。

## ローカルで見る

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開いてください。

## 設定メモ

- マジカル☆しょうゆ戦士の表情は、どの場面でも一切変化しません。
- 必殺技は「ジャスティス♡マグナム」を含む全9種。いずれも素手です。
- この作品はフィクションです。実在の人物・団体・しょうゆとは関係ありません。
